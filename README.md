# Генератор ссылок

Сайт создаёт до 10 000 разных URL за раз. Перед каждой партией можно указать HTTPS-адрес назначения. Цель закодирована в ссылках `/to/<цель>/<код>`, поэтому старые ссылки сохраняют прежнее направление. Старые ссылки `/go/<код>` продолжают вести на `https://oopsie.bio/ashleywow`.

В списке можно фильтровать и сортировать ссылки по адресу назначения, выбирать отдельные ссылки или сразу все отфильтрованные, выгружать выбранное в `.xlsx` и удалять выбранные, отфильтрованные либо весь список. Список хранится только в браузере; удаление не отключает уже выданные ссылки. Новые ссылки длиннее из-за встроенной цели.
