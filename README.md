# Генератор ссылок

Сайт создаёт до 10 000 разных URL за раз. Перед каждой партией можно указать HTTPS-адрес назначения. Цель закодирована в ссылках `/to/<цель>/<код>`, поэтому старые ссылки сохраняют прежнее направление. Старые ссылки `/go/<код>` продолжают вести на `https://oopsie.bio/ashleywow`. Список созданных адресов хранится только в браузере; для резервной копии скачивайте CSV. Новые ссылки длиннее из-за встроенной цели.
