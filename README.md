# Генератор ссылок

Статический сайт создаёт до 10 000 разных URL за раз. Все пути `/go/<код>` перенаправляют на `https://oopsie.bio/ashleywow` через Vercel. Созданные адреса сохраняются только в браузере, поэтому для резервной копии скачивайте CSV. Для смены конечного адреса измените `destination` в `vercel.json` и разверните проект заново.
